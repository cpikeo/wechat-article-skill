# 案例与回归素材

这些是既有教学／排版语料，不是已经核验并发布的新闻稿。事实修订必须在成品可见，不只放在本说明里。

|语料|独立覆盖|事实与发布状态|
|---|---|---|
|skills / paper|列表、h3、代码、表格、data、转场|观点与演示；数字声明假设；无封面，不可直接发布|
|portrait / letter|叙事、引用、环境图todo|虚构人物与对话可见声明；删除脱节铜排图；todo不可发布|
|visual / frost|airy、deck、bars、说明图、中前部peak|485/950回查IEA 2026原报告；全球数据中心而非AI独立用电；历史期与预测分开|
|brief / folio|dense、待补封面、语义表格与正负百分点|不再编造行业四档NDR；教学假设、不是投资统计；缺封面|
|longread / paper|长文、目录、观点论证|删除不同单位共轴的伪数量图；经验观点不是行业寿命统计|

共享封面1080×460、铜排1264×842均保留；原始素材获取／授权记录缺失，公开发布前必须补证或替换。铜排沿用既有AI生成示意标识；不得改成实拍。fixtures/tiny.png为低分辨率负例。

selftest保留5篇的主题、图片数、peak、目录、开篇结构基准，不把它们叫作文案质量分。新增缺陷测试覆盖图表精确比例、输入错误、真实HTTP响应解析、实体路径、跨目录交付、陈旧稿、待补稿与默认草稿安全。删除数字重复、独立封面、短文目录和转场配额的机械护栏；这些回到SKILL判断，不使合格内容为测试改稿。

`--shots`复用已经渲染的5篇，检查320/360/390/430px溢出、图片加载、预览与正文内容、实际copy事件设置的HTML及内联样式，再存390px·2x截图。显式请求而环境缺失即失败。复制验证是在Chromium里，不是公众号编辑器清洗测试。
