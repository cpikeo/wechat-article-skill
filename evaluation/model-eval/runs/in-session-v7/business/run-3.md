> 先给最容易被误读的那一步：生产率高让少工作成为可能；“可能”不等于“必然发生”。

## 先看差异

::: data 单位：小时/年（人均）
约2500｜柬埔寨
不足1600｜瑞士
约900｜两者相差
:::

::: note 来源与口径
Our World in Data（2020-12-21）；人均年工时；单位为小时/年。
:::

瑞士的人均收入是柬埔寨的十五倍以上。收入与工时的方向相反，这正是需要解释的地方。

## 生产率如何进入解释

劳动生产率是每小时劳动带来的经济产出。德国、瑞士接近每小时70美元，柬埔寨约每小时2美元。

每小时产出更高，维持同等收入所需的工时就更短。这条链条解释的是可能性。

## 反例把结论收窄

美国和新加坡的工时高于生产率相近的国家。若生产率是唯一原因，这个现象不该出现。

因此更稳的说法是：生产率是条件之一，制度与选择决定这个条件是否兑现。

## 时间上的同向变化

1950年至数据所及年份，多数国家收入上升、工时下降；德国人均GDP增长超过十倍，工时接近减半。同向变化支持关联，不单独证明因果。

::: unknown 未确认
各国工时统计是否采用同一口径、是否包含兼职，原文未说明；美国和新加坡的数值也缺失。跨口径比较的结论一律不外推。
:::
