> 【2025年7月3日讯】微软7月2日宣布裁员，约9000人、不足4%的员工受影响。裁员与AI投入的关系目前只有分析，没有公司确认。

## 发生了什么

微软7月2日宣布全球裁员约9000人，占22.8万员工总数不足4%。这是当年第四轮裁员。

游戏部门受影响：《Perfect Dark》重启项目、《Everwild》等游戏取消，负责前者开发的工作室The Initiative也将关闭。

## 年内四轮的时间线

::: data 单位：人
9000｜7月2日宣布
6000｜5月，超过此数
300｜6月，至少此数
:::

::: note 来源与口径
维基新闻（2025-07-03）转述CNBC；人数为裁员岗位数，非部门人数。
:::

微软当年1月裁员不足1%；加上这一轮，年内裁员总数超过1.5万人。上述数字来自知情人士向CNBC的透露。

## 公司自己的说法

微软表示，裁员是为了在多变市场中优化公司架构。其发言人对BBC称公司持续调整组织架构以适应市场。

::: unknown 待确认
800亿美元AI投入与本次裁员是否有直接关系，微软没有回应。把两者写成因果，目前没有出处。
:::
