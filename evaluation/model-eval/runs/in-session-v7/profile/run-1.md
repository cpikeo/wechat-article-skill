> 1930年12月30日出生，浙江宁波人；1951年考入北京大学医学院药学系；2015年获诺贝尔生理学或医学奖。

## 她是谁

屠呦呦，中国药物化学家，中国中医科学院终身研究员兼首席研究员，抗疟药青蒿素和双氢青蒿素的发现者。

1951｜考入北京大学医学院药学系生药专业
