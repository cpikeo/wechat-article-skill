> 从 1930 年到 2015 年，八十五年间的一条路径：宁波出生，北大药学系，青蒿素，诺贝尔奖。

## 起点

屠呦呦，1930年12月30日出生，浙江宁波人。

## 求学

1951年，她考入北京大学医学院，在药学系生药专业学习。

1955年毕业后，她曾培训中医两年半，随后被分配到中医研究院中药研究所工作。

## 研究

她多年从事中药和中西药结合研究。原条目把她的突出贡献写成两项：青蒿素和双氢青蒿素。

这句话是概括，不是过程。谁参与了提取、如何做临床、失败过多少次，原文都没有写。

## 奖项

2011年9月，拉斯克临床医学奖。

2015年10月5日，与威廉·C·坎贝尔、大村智共同获得诺贝尔生理学或医学奖。

此外还有国家最高科学技术奖和共和国勋章等荣誉。
