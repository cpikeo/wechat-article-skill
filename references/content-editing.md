# Content Editing（润色，可选）

**默认排版不擅改原文**。只有用户明确说"润色/优化文笔/调整节奏/检查一致性"时才执行，改动前后让用户看清楚差异。

## 一、句子节奏

- 标连续 3 句以上字数差 ≤5 字的地方，有意让长短句交替（长句给信息量→短句给停顿）。
- 连续 3-4 段纯文字无引用/图片/列表打断，建议在语义合适处插入组件或建议配图，不强制拆内容。

## 二、语气原型（不模仿具体真人）

| 标签 | 语感 |
|---|---|
| 极简克制 | 短句、去形容词、只留事实判断 |
| 文学温润 | 意象化描写、感官细节多、节奏舒缓 |
| 杂志国际感 | 理性克制、专业术语准确、长句逻辑清晰 |
| 慢生活自然 | 具体场景切入、语气亲近、少说教 |
| 深度报道理性 | 数据/引语支撑观点、段落有论证结构 |

婉拒"模仿具体在世作者"的请求，改用上面风格标签描述。

## 三、术语/单位/日期一致性（脚本检测，不自动改）

```bash
python3 scripts/content_consistency_check.py <文章.md 或 .html>
```

检测：同一概念中英/全称简称混用、日期格式不统一（"2026年7月17日"vs"2026-07-17"）、数字全角半角混用、单位写法不统一（"km"vs"公里"）。只列出位置，用哪种写法由用户决定。

## 四、结构判断（定性，不编数字）

通读后回答三拍问题（能指出文中具体位置，不打分数）：
1. **开场**：前 1-2 段有没有钩子（案例/反常识/明确读者利益）？
2. **转折**：中段有没有视角/论点上的递进，还是一马平川？
3. **收束**：结尾是否回到开场钩子形成闭环，还是突兀 CTA？

答不出具体位置说明这一拍缺失，给出具体修改建议，不喊"节奏感不够"这类空话。

**不做的事**：不编"62% 读者在第三屏跳出"这类没有真实数据的数字；不画"情绪曲线"量化分数。
