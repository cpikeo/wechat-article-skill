# Decide：设计判断

渲染器只执行。每次排版先写 Decision。

优先级：**Plain Text > Typography > Divider > Image > Data > 原语**。

## 怎么填

| 行 | 决定 | 常见错误 |
|---|---|---|
| Audience | 语气、密度、距离 | 「大众」= 没判断 |
| Purpose | 锚点放哪 | 「传播品牌」——读者无所得 |
| Core Claim | Peak 的内容与位置 | Peak 写成段落，或金句不是主张 |
| Hierarchy | 主 / 次 / 可删 | 每节一样响 |
| Tone | 主题 | 按心情换色 |
| Density | 留白 0.8 / 1.0 / 1.2 | 短文挤死；教程冲散 |
| Rhythm | 390px 上的滑动 | 首屏堆 kicker+deck+lead+TOC+图 |
| Anchor | 0–2 处 | quote、data、大图一起上 |
| Image | 每张图的 Why | 「这里空，所以放图」 |
| Cut | 至少一项 | 只加不减 |

视觉权重服从：**Core Claim > Section Claim > Evidence > Explanation > Metadata > Decoration**。

禁止：标题失控、每段加粗、每节卡片、每个数字做成 data、每段配图、原语互抢。

## 六个 Editorial Mode

不是六套换色。字号 6 级由渲染器锁定。主题决定气候、标记语言、衬线出现的位置。

- **paper 静纸**：沉静克制。观点、分析、教程、复盘、默认。暖石 + 干苔。数字章节、细线高潮、圆点转场、平切图片。
- **letter 暖信笺**：温暖叙事。人物、故事、随笔。信笺 + 火漆。圆点章节、暖底高潮、细线转场、柔角图片。
- **ink 酌墨**：笃定有分量。评论、书评、年度。象牙 + 干血。图章章节、深色高潮、衬线标题与引文、线框图片。
- **frost 北霜**：冷静报道。调查、科技、旁观。北昼 + 峡湾。数字章节、冷底高潮、细线转场、平切图片。
- **bone 素作**：物与工艺。品牌、空间、材料。石膏 + 铜尘。无标记章节、细线高潮、衬线标题与引文、平切图片。
- **folio 特稿**：杂志特写。文化、人物特稿。油墨 + 干朱。数字章节、深色高潮、圆点转场、线框图片。

气质都不对时走文末「新主题」。禁止再加一套只换色的主题。

同一主张换读者，构成必须变。只改 `theme:` 字段 = 判断没有发生。

失败样例：教程套 ink 深色 Peak；叙事每节一张「氛围」图；短文加 TOC；无图原稿补三张配图；Decision 写了 Cut，Compose 一项都没删。

## 强调与图片

普通信息不强调。`**` 弱强调。`==` 全篇 ≤3。结论进 Peak。允许只有 Peak 一处强调。

图片职责（title 位，没写 = 必须改）：信息 / 证据 / 氛围 / 隐喻 / 停顿 / 锚点 / 数据。

生成或选图，提示词覆盖：**意图 · 主体 · 构图 · 材质 · 光线 · 色盘（服从主题）· 媒介 · 留白 · 裁切（含 390px 竖裁）· 与文章的关系**。宽 ≥1200px（竖图短边 ≥800px）。宁留 `todo`，不塞低质量图。

图标只用文字、数字、Unicode（→ ✓ · —）、CSS 几何。不用 emoji 做结构，不用 SVG / 图标库。

## 节奏与删除

首屏只留 kicker、标题、一句钩子。deck 与 lead 不要叠。TOC 在 lead 之后且 ≥3 章。高潮不要在第一屏，也不要贴着 CTA。中段给一次纯正文恢复。

Gate 3 至少找：一个可删元素、一个可弱化层级、一个可合并结构、一段可缩短文字、一处可取消装饰。**Subtraction Before Addition。**

## Gate 3 · Art Direction（通读预览）

不追求规则全满足。追求成品有没有高级判断。

1. 首屏是否建立阅读欲？
2. Core Claim 是否成为视觉中心？
3. 信息层级是否自然？
4. 是否存在视觉噪音？
5. 图片是否真正有意义？
6. 是否有重复视觉语言（两个高潮、两处居中）？
7. 是否有不必要的原语？
8. 滑到中段是否疲劳？
9. 是否有节奏变化？
10. **哪一个元素应该消失？**

结论只写必须改 / 建议改 / 保留。不打分。

## 新主题

只在六种人格都不成立时增加——加的是 Editorial Mode，不是色板。

1. `assets/themes.json` 按现有键加一节（含 `image`: flush / soft / line），不发明新键。
2. `eval/` 任选一篇 `render.py --theme 新主题`，通读 390px 预览。
3. 三关过后再登记到「三个 Editorial Mode」。
