# Decide：设计判断

渲染器只负责执行，这里的判断负责设计。每次排版先写 Decision（9 行），再动手。

## Decision 九行

| 行 | 问什么 | 决定什么 |
|---|---|---|
| Audience | 读者是谁 | 语气、密度、距离感 |
| Purpose | 读完后应该理解/相信/行动什么 | 锚点分布 |
| Core Claim | 全文最值得记住的一句话 | Visual Peak 的位置与内容 |
| Tone | 沉静/温暖/笃定/轻快 | 主题选择 |
| Density | dense / standard / airy | 留白倍率（0.8 / 1.0 / 1.2） |
| Visual Anchor | 除 Peak 外，还有哪 1–2 处值得停留 | quote / data / table 的取舍 |
| Image Strategy | 每张图为什么存在 | 保留/删除/待补 |
| Design Language | paper / letter / ink | 整篇的视觉人格 |
| Composition | 版面节奏（一句话） | 开头策略、转场次数、结尾收束 |

## 主题人格

- **paper 静纸**：沉静克制。观点、分析、教程、复盘、通用默认。数字编号、细线高潮、圆点转场。
- **letter 暖信笺**：温暖叙事。人物、品牌、故事、随笔。圆点编号、暖底高潮、细线转场。
- **ink 酌墨**：笃定有分量。评论、书评、行业观察、年度总结。图章编号、深色高潮、图章转场、衬线标题。

气质冲突（三套都不对）时如实说明，走「新主题」流程，不硬套。

## 强调纪律（Selective Emphasis）

普通信息不强调；重要信息用字重（`**`）；关键判断用细线（`==`，全篇 ≤3）；核心结论进 Peak。允许整篇只有 Peak 一处强调——强调越稀缺越有价值。

## 图片职责（8 种）

情绪 / 语境 / 证据 / 解释 / 转场 / 氛围 / 品牌 / 高潮。写在图片 title 位（`"职责"`），渲染器会检查：没写职责的是"必须改"，直接交付不了。

选图标准：专业摄影优先；构图、光线、色温与主题一致；宽≥1200px（竖图短边≥800px）。宁可留待补位，不塞低质量图。

## 图标纪律

只用文字、数字、Unicode 符号（→ ✓ · —）、CSS 几何（圆点/细线/图章圆环）。不用 emoji 做结构图标，不用 SVG，不用图标库。

## Gate 3（通读预览，四问）

1. 首屏凭什么让人继续读？（标题+引言是否成立）
2. 全文视觉高潮在哪里？是不是 Core Claim？
3. 哪一个元素删掉反而更好？（至少找到一个候选，再决定删不删）
4. 从第一屏滚到最后一屏，像同一本杂志吗？

结论只写必须改/建议改/保留。不打分。

## 新主题

1. 在 `assets/themes.json` 加一节（对照现有三节填 20 个键，不发明新键）。
2. 用 `eval/` 任选一篇跑 `render.py --theme 新主题`，通读预览。
3. 三关全过后登记到本文件的「主题人格」。
