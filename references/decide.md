# Decide：判断

JUDGE / EDIT 两步读这份。渲染器只执行确定性部分；**这里讲的是怎么下判断。**

优先级：**Plain Text > Typography > Space > Divider > Image > Data > 原语**。

## 怎么填 Decision

| 行 | 决定什么 | 常见错误 |
|---|---|---|
| Audience | 语气、密度、距离 | 「大众」= 没有判断。写「通勤时滑手机的人」才有用 |
| Intent | 读完应该理解 / 相信 / 做什么 | 「传播品牌」——读者无所得 |
| Core Claim | 全文最值得记住的一句，落入 Peak | 写成段落；或者金句不是主张 |
| Hierarchy | 主 / 次 / 可删 | 每节一样响；不敢降级 |
| Cut | 准备删掉或降级的（至少一项） | 只加不减 |
| Mode | 六种人格之一（= 主题气候） | 按心情换色；气质不对硬套 |
| Density | dense / standard / airy | 短文挤死；教程冲散 |
| Rhythm | 380px 上的滑动节奏：钩子 → 停顿 → 高潮 → 恢复 → 收束 | 首屏堆 kicker + deck + lead + TOC + 图 |
| Anchor | Peak 之外 0–2 处停留 | quote、data、大图一起上 |
| Thesis / Grammar / Budget / Slots / Cover | 见 `direction.md` | 用「要不要图」代替「这里需要什么职能」 |

视觉权重服从信息权重。允许全文只强调一处。

## 六种 Editorial Mode

不是六套换色，是六种气候与标记语言。字号 6 级由渲染器锁定，主题只决定气候、标记、衬线的位置。
`theme:` 的取值就是这里的六个人格名。

- **paper 静纸**：沉静克制。观点、分析、教程、复盘、默认。暖石 + 干苔。数字章节、细线高潮、圆点转场、平切图片。
- **letter 暖信笺**：温暖叙事。人物、故事、随笔。信笺 + 火漆。圆点章节、暖底高潮、细线转场、柔角图片。
- **ink 酌墨**：笃定有分量。评论、书评、年度。象牙 + 干血。图章章节、深色高潮、衬线标题与引文、线框图片。
- **frost 北霜**：冷静报道。调查、科技、基础设施、旁观。北昼 + 峡湾。数字章节、冷底高潮、细线转场、平切图片。
- **bone 素作**：物与工艺。品牌、空间、材料、器物。石膏 + 铜尘。无标记章节、细线高潮、衬线标题与引文、平切图片。
- **folio 特稿**：杂志特写。文化、人物特稿。油墨 + 干朱。数字章节、深色高潮、圆点转场、线框图片。

同一篇主张，换读者就要换构成；只改 `theme:` 字段 = 判断没有发生。
气质都对不上时，走文末「新主题」，不要硬套。

## 删除与强调

**Subtraction Before Addition。** 每篇至少找：一个可删元素、一个可弱化层级、一处可合并结构、一段可缩短文字、一处可取消装饰。

普通信息不强调。`**` 弱强调；`==` 全篇 ≤3；结论进 Peak。
禁止：标题失控、每段加粗、每节卡片、每个数字做成 data、每段配图、原语互抢、图片来源与正文无关。

## 判断层面的失败样例

- 教程套 ink 深色 Peak，把步骤页做成悼词
- 叙事每节配一张「氛围图」，读起来像相册
- 短文加 TOC；无图原稿硬补三张配图
- Decision 里写了 Cut，Compose 一项都没删
- 同一主张只换了 `theme:`，构成完全没变

## 新主题

只在六种人格都不成立时增加——加的是 Editorial Mode，不是色板。

1. `assets/themes.json` 按现有键加一节（含 `image`: flush / soft / line），不发明新键、不加字号。
2. `python3 scripts/render.py --specimen` 生成六格对照板，看它是不是真的区别于已有六种。
3. 用 `eval/` 任一用例渲染并通读 390px：`python3 scripts/render.py eval/skills.md --theme 新主题`。
4. 三关过后，把气候与用途补进本文档的六人表（变七人表）。
