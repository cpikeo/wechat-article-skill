# Design System：编辑设计判断中枢

本文档是**唯一权威的设计判断参考**：视觉层级、节奏、版式比例、配色预设、9 维 Design Language、图标与图片判断、Editorial QA 清单。排版前必读，排版中随时参照。

---

## 一、Field > Line > Type > Container

这是所有判断的元原则，优先级从高到低：

1. **Field（场域/留白）**：空间是最强的设计语言。大留白比任何装饰更高级。
2. **Line（线）**：细线、竖线、圆点、分割符用来建立秩序和节奏；用中性色，不用 accent。
3. **Type（文字）**：字重、字号、字距、断行本身就能完成大部分层级表达。
4. **Container（容器/卡片）**：最后才用——只有当空间+线+文字都不够时，才引入底色/边框/阴影。

**反模式**（一律禁止）：组件堆叠、视觉噪音、过度圆角、廉价渐变、无意义阴影、营销号式强调、机械关键词下划线、每段强行装饰、四周虚线框（仅居中待补素材块例外）。

## 二、视觉层级（三层，所有 Design Language 通用）

| 层级 | 作用 | 全篇频率 | 手段 |
|---|---|---|---|
| **Anchor（锚点）** | 最强：Core Claim / 关键数据 / CTA / 金句 | **≤4 处** | accent 色、深色底白字金句卡 |
| **Mark（标记）** | 正文关键词，段落级重点 | 每段 1-2 处 | accent 色细下划线（1px） |
| **Structure（结构）** | 引用块、提示、列表、章节、署名 | 按需 | 浅底色、中性灰、字重、留白 |

**关键纪律**：结构性重复元素（列表圆点、竖线、页眉细线、图章描边）一律用中性/暖灰色，**不占用 accent 配额**。accent 只给真正稀缺的锚点。

## 三、版式与节奏

### 字号体系

- 正文字号：**15px**，行高 1.9（WeChat 移动端实测最优，不盲目照搬网页 18px/2.0）。
- 字号阶梯严格 **6 级**：11/13/15/16/17/22px，任何组件不得额外开新字号。
  - 11px：micro（标签/编号/图注/署名，统一 `letter-spacing:1px/1.5px`）
  - 13px：caption（副标题、导读、提示）
  - 15px：body（正文，行高 1.9）
  - 16px：quote（引用块专用）
  - 17px：h2（章节标题）/ 金句
  - 22px：h1（文章大标题）
- **中文大字号标题禁用负字距**（`letter-spacing` 负值），会导致字挤在一起。

### 段落节奏

- 单句/单段 **40-70 个汉字**，超过在语义断点拆段，不拆到词语中间。
- 大号标题 ≤2 行，按语义断行（不按字数硬切）。
- 连续 **3-4 段纯文字** 无引用/图片/列表打断时，必须在语义合适处插入组件打断节奏（引用/提示/图片/分割线，择一，不叠加）。
- 引用优先居中排布（各主题的引用组件均居中），不用左对齐大段引用。
- 英文短语/数字单位（≤15字符，如 "AI Content Design OS"、"v1.0"）套 `<span style="white-space:nowrap;"><span leaf="">...</span></span>` 防中间断行。

### 垂直留白（WeChat 安全改编）

| 元素 | 留白 |
|---|---|
| 章节之间 | 36-44px（按主题） |
| 图片上下 | 32-34px |
| 段落之间 | 20-22px |
| 引用/卡片上下 | 36px |

不要照搬网页 72-88px 的大留白，会让公众号阅读变得拖沓。

### 标点避头尾

所有 Design Language 的全局容器已加 `line-break:strict;`，让 WebView 自动应用东亚文字断行规则，不需要手动处理。

## 四、图标判断（不是装饰，是信息语言）

**三种安全技术**（已验证公众号兼容）：

| 技术 | 示例 | 适用 |
|---|---|---|
| **Unicode 排版符号** | `→` `✓` `◎` `·` `※` `◇` `♡` | 结构标记、图章、步骤、收尾（最推荐，颜色可控、跨平台稳定） |
| **CSS 几何图形** | `<span style="width:6px;height:6px;border-radius:50%;background:#...">` 圆点/竖线/细线 | 装饰性点、引导线、分割条 |
| **数字 / 文字编号** | `01` `PART` `CHAPTER` | 章节号、步骤号 |
| **Emoji（酌量）** | 👍 👀 📮 | 仅在暖信笺/静纸的结尾互动区等已定义场景使用；一篇文章 emoji 总数不超过结尾互动区那 3 个 |

**图标使用纪律**：
- 尺寸、线性重量、间距、视觉重心、色彩必须统一。
- **禁止**：SVG、图标库（Lucide/Phosphor/Heroicons 等）、第三方 Icon CDN（unpkg/jsdelivr）、彩色 emoji 堆叠、为"看起来高级"加图标。
- 酌墨主题全篇不用彩色 emoji，统一用「细描边圆环 + Unicode 排版符号」（图章式视觉语言）。

## 五、图片判断（Visual Asset Judgment）

每张图片必须先回答：
> **这张图承担什么职责？** 建立情绪？解释概念？提供证据？章节转场？视觉高潮？提升品牌质感？

**答不出职责的图删掉。**

### 图片选择优先级

1. **高审美摄影**：自然光线、留白充分、材质细节、建筑与自然
2. **艺术化场景**：去人工感、色调克制、与主题色温一致
3. **高质量信息图**：数据可视化、流程说明（PNG/JPG 位图，非 SVG）
4. **品牌级视觉素材**：产品图、场景图、品牌视觉

**避免**：为填空配图、图片过密、图库感摆拍、千篇一律 AI 插图、风格不统一、与正文无关的装饰图。

### 技术规则

- 图片 `max-width:100%;height:auto;display:block;margin:0 auto`，不用 `width:100%` 强制铺满（小图会被拉伸变糊）。
- 相邻两张图片之间正文字数 ≥12 字，避免连续刷图感。
- 配图视觉气质必须与所选 Design Language 的"阅读人格"一致（克制主题不配高饱和强对比图）。
- **不直接引用图库外链**（Unsplash/Pexels/Pixabay 原始 URL）：手动流程由用户在编辑器自上传本地图；API 直发流程脚本自动上传本地图替换为微信域名。
- SVG 插图（unDraw/Storyset 等）必须先导出为 PNG/JPG，再按图片流程处理。
- GIF 动图与普通图片一样处理，加"GIF 动图"角标。
- 图片说明无可编造就删除，不空 alt 编造说明。

### 待补素材

使用统一的居中待补板块（见 themes.md「待补素材占位」组件），图标按类型换：🎬 视频/录屏、🖼 图片、📊 信息图、📎 附件。这是唯一允许虚线框的场景。

## 六、Design Language 9 维定位

用序数标签（低/中/高）描述一套 Design Language 的气质，**不用编造百分比数字**。

| 维度 | 含义 |
|---|---|
| **Silence**（留白安静度） | 留白 vs 内容密度 |
| **Weight**（视觉重量） | 卡片/阴影/色块的密度 |
| **Breathing**（呼吸感） | 段落/章节间隔节奏 |
| **Rhythm**（节奏变化） | 组件类型交替丰富度 |
| **Contrast**（对比强度） | 强调色/正文色对比 |
| **Pace**（阅读速度感） | 催促快滑 vs 鼓励停留 |
| **Emotion**（情绪基调） | 沉静/温暖/笃定/轻快 |
| **Temperature**（色温） | 冷调/暖调/中性 |
| **Distance**（作者距离感） | 贴近读者 vs 讲台式疏离 |

三套内置 Design Language 的定位：

| 维度 | 静纸 | 暖信笺 | 酌墨 |
|---|---|---|---|
| Silence | 高 | 高 | 高 |
| Weight | **低**（几乎无卡片阴影） | 中（暖卡片+柔和阴影） | 低-中（细描边卡片，无阴影） |
| Breathing | 高 | 高 | 高 |
| Rhythm | 中（靠留白制造变化） | 中-高（情绪停顿/证言/时间线） | 中（衬线对比制造层次） |
| Contrast | 低（单一accent） | 低 | 中（衬线vs无衬线对比） |
| Pace | 慢 | 慢 | 慢 |
| Emotion | 沉静、克制 | 温暖、感性 | 笃定、有分量 |
| Temperature | 中性偏暖 | 暖 | 暖（偏深） |
| Distance | 适中偏近 | 近（像一封信） | 中（像一本评论集） |

设计新主题时先用这 9 维写一句话定位，再倒推色板/组件；诊断"气质散"时逐维对照。

### 可选装饰工具（按需，非默认）

```

```

静纸/酌墨不用阴影；暖信笺仅在图片容器和金句卡用两处，不是处处加。

## 八、平台不可行效果（如实告知，不假装能做）

| 效果 | 能否落地 | 原因 |
|---|---|---|
| Fog 雾化背景 | ❌ | 需要 position:absolute 叠层，平台禁用 |
| Noise/Film Grain 噪点颗粒 | ❌ | 需要背景纹理图 + blend-mode，不支持 |
| Paper Texture 纸张纹理 | ❌ | 同上 |
| Glass Mist 毛玻璃 | ❌ | 依赖 backdrop-filter:blur()，不在白名单 |
| Grid Layer 杂志网格线 | ❌ | 需要 display:grid 或背景网格图 |
| Baseline Grid 基线网格 | ⚠️ 精神可及 | 靠字号阶梯+固定行高实现节奏统一，不做像素级对齐 |
| Soft Gradient 微渐变 | ✅ | linear-gradient 可用 |
| Ambient Glow 空气感阴影 | ✅ | box-shadow 可用，调参数即可 |
| 滚动/悬停动效 | ❌ | 粘贴时可能复制到 opacity:0 中间态导致文字消失 |

用户要求这些效果时，如实说明平台限制并提供可行替代（微渐变/空气感阴影），不用近似效果冒充。

## 九、Editorial QA 清单（必跑，不可省）

跑完两个脚本、清完 ERROR 之后，**通读全文**（想象在手机上滚动阅读）逐条判断：

### 结构层
1. **首屏抓人**：标题+引言在手机首屏能否看出这篇值得读下去？引言不是复述标题。
2. **Core Claim 位置**：视觉高潮（金句卡/最强锚点）落在全文最核心的那句话上，不是随手放在某个位置。
3. **节奏三拍**：(a) 开场有没有钩子（案例/反常识/明确利益），还是只在铺背景？(b) 中段有没有视角/论点转折，还是一马平川？(c) 结尾是否回到开场钩子形成闭环，还是生硬 CTA？
4. **结尾克制**：签名区/CTA 只一处，语气和全文调性一致，不突然切换成营销号话术。

### 视觉层
5. **视觉呼吸感**：相邻高密度组件（卡片/表格/多图）之间有纯文字缓冲，不让读者连续翻过三个卡片喘不过气。
6. **图文比例**：>1500 字长文中间没有任何打断会疲劳；图片/组件过多盖过文字会"花而不实"。
7. **强调正确性**：accent 锚点都落在"核心结论/关键数据/最该记住的一句"上，不是随手强调了不重要的形容词（脚本能数数量，数不出用得对不对）。
8. **留白与密度**：没有连续 3 个以上相同样式的区块，没有大段无标点文字墙，字号严格 6 级。

### 细节层
9. **响应式**：图片 max-width:100%，容器无固定大宽度，长内容用卡片化表格不溢出。
10. **标题堆叠**：没有连续两个标题级组件中间无正文/图片/引用。
11. **配方服务内容**：主题配方表是默认值，内容撑不满某个组件就减配，不编内容凑数。
12. **图片判断**：每张图都有明确职责，没有为填空配图，没有风格不搭的图。

**结果输出**：问题清单 + 严重度（必须改/建议改/可保留）+ 修改决策。**禁止**输出"综合审美 97 分"这类编造数字。

## 十、命名语义别名（理解用，不改 hex）

UI 命名对应的语义角色，帮助按"用来做什么"而不是"第几个颜色"思考：

| UI 命名 | 语义别名 | 用途 |
|---|---|---|
| Primary | Reading Anchor | 正文主文字、结构色 |
| Accent | Insight | 稀缺锚点（≤4 处） |
| Border | Whisper | 分割线、卡片边框（中性色） |
| Background page | Paper | 引用块/卡片底色 |
| Muted | Caption | 次要说明、署名、图注 |
