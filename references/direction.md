# 图片艺术指导

本文件是 `SKILL.md` 图片契约的工艺展开：怎么想、怎么写提示词、怎么淘汰。它不提供固定模板，只提供判断方法。

**核心命题**：一张合格的配图同时成立三件事——**有观点**（它替文章说了哪句话）、**有画面**（构图与光线本身值得看）、**有可信度**（材质、比例、细节经得起放大）。缺一件，它就是装饰。

编辑只对两件事负责：**决定这张图说什么**，以及**判断它是否成立**。渲染器不判断审美，也不该假装能判断。

## 0. 先决定要不要图

配图不是义务。出现下列任一情况，用文字：

- 这一段的信息是概念关系、流程或对照——用 `::: data`、表格或短句列表比图清楚。
- 图只能复述段落字面（写"团队协作"就画几个人围着桌子）。
- 找不到能承载观点的具体场景，只能靠"氛围感"填空。
- 本文已经有三张同景别、同光源的图，第四张只会稀释节奏。

图片预算按字数：≤800 字 1 张；≤2000 字 3 张；>2000 字 4 张；封面单列。少而准优于多而匀。

## 1. 策划单（生成或选图之前必须写完）

七项，缺一不可。写不出来的那一项，就是你还没想清楚的地方。

| 项 | 要写什么 | 反例 |
|---|---|---|
| 内容洞察 | 这张图替哪一句、哪一节说话？它要让读者多知道/多感觉到什么 | "配一张科技感的图" |
| 视觉概念 | 真实场景 / 概念隐喻 / 艺术静物 / 纪实 / 博物馆式 / 科学可视化，选一或组合，并说明为什么是它 | 六种都要 |
| 主体与动作 | 画面里有什么、什么状态、正在发生什么；主体占画面多少 | "一个物体悬浮在模糊背景前" |
| 镜头与构图 | 景别（远/全/中/近/特/微距）、机位（平/俯/仰/侧/切入）、主体位置、前后景纵深、负空间比例 | "居中大特写" |
| 光影与材质 | 光源方向与性质（自然侧光/窗光/逆光/单点聚光）、投影方向、材质物理细节 | "光影唯美" |
| 色彩方向 | 主色/辅色/背景色/一处强调色；饱和度与色温 | "高级感配色" |
| 输出约束 | 画幅、主体安全区、`cover_focal`、排除项（文字、水印、畸变、多余手部） | 无 |

**示例（可直接照此写）**：

> 洞察：一人公司同时承担策略、制作与交付，桌子就是组织架构。
> 概念：艺术静物——把"三个角色"压在同一张桌面的三组物件上。
> 主体：一张旧木桌，左端摊开的手写稿与铅笔，中部一台合上的笔记本电脑，右端一只凉透的陶瓷杯，杯壁有水痕。
> 镜头：50mm 平视略俯，主体偏左下，右上方留大片空桌面；前景桌沿入画 1/5。
> 光影：左侧窗光，柔和但方向明确，投影朝右；木纹与纸纤维清晰，电脑外壳有细划痕。
> 色彩：暗橄榄与胡桃木为主，纸为唯一亮面，无其他饱和色。
> 约束：3:2 横构图，主体安全区留中偏左，无文字无水印，不出现人手。

## 2. 提示词的写法

**用物理条件代替形容词。** 形容词是审美判断，模型只能猜；物理条件是可执行指令。

| 不要写 | 改写成 |
|---|---|
| 高级感、电影感、8K、masterpiece | 左侧 45° 窗光；35mm 视角；主体偏右三分线；背景为未打光的深灰墙面 |
| 极简风 | 画面上部 40% 为空白墙面，仅一条水平阴影线 |
| 质感很好 | 亚麻织物可见经纬与轻微起球；陶器釉面有细开片 |
| 科技感 | 金属拉丝表面反射一条冷白灯带；无发光特效，无粒子 |
| 氛围感 | 逆光穿过薄雾，尘埃颗粒可见，主体呈半剪影 |

提示词顺序固定，越靠前权重越高：**主体与动作 → 空间与镜头 → 光线 → 材质 → 色彩 → 画幅与排除项**。一条提示词只解决一张图的一个观点；不要在一张图里塞两个隐喻。

## 3. 六种视觉语言，按内容选

| 语言 | 什么内容用它 | 关键控制 | 一眼就假的信号 |
|---|---|---|---|
| 编辑摄影 | 观点、文化、行业观察 | 构图有取舍，主体不必居中；允许不完美 | 商业图库式微笑、留白均匀、光线无方向 |
| 概念摄影 | 抽象论点、评论 | 一个可记忆的视觉符号，其余全部让位 | 符号太直白（把"增长"画成向上的箭头） |
| 艺术静物 | 器物、工艺、慢叙事 | 材质、比例、留白；桌面是舞台不是背景 | 塑料反光、悬浮、无投影、表面无使用痕迹 |
| 纪实人物 | 人物、现场、报道 | 自然动作、环境关系、可用光 | 摆拍姿势、磨皮、眼神光太完美 |
| 博物馆式 | 标本、器物、知识 | 中性背景、精确比例、均质光 | 装饰性堆砌、戏剧化打光 |
| 科学可视化 | 机制、结构、流程 | 信息准确、层级清楚、零虚构数据 | 用生成图冒充实测数据 |

一篇之内可以混用，但**摄影语言必须统一**：同一篇文章不要一半自然光、一半影棚硬光。

## 4. 让一组图成为一组

整篇图的识别度来自一致性，不是每张都精彩：

- **一个光源**：全篇同一方向（例：左侧窗光），投影方向一致。
- **一个色温**：暖或冷选定后不摇摆；强调色只出现一次。
- **一个镜头家族**：35mm 环境、50mm 关系、85mm 细节；不要在同一篇里混广角畸变与长焦压缩。
- **一条景别线**：远景定场 → 中景关系 → 近景动作 → 特写材质。至少两级，最多四级。
- **一致的"脏"**：允许灰尘、划痕、水痕、折角。真实感来自不完美，不是来自分辨率。

## 5. 整篇图片叙事

| 位置 | 任务 | 构图重点 |
|---|---|---|
| 封面 | 建立视觉记忆 | 单一主视觉、强概念、显式焦点；2.35:1 与 1:1 两个裁切都要成立 |
| 正文首图 | 建立情境 | 具体场景与主体，定场景别，不重复封面语言 |
| 章节图 | 辅助观点 | 与上一张换景别或换机位 |
| 解释图 | 解释机制 | 结构清晰、层级分明、零虚构 |
| 证据图 | 可核对记录 | 真实来源，不用生成图 |
| 细节图 | 材质与可信度 | 特写/微距，纹理清晰 |
| 结尾图 | 情绪收束 | 安静、留白、有余韵，不重复开篇构图 |

封面三原则：**一个焦点、一处留白、一条视线**。封面不是海报，不要放字。

## 6. AI 生成图的六种默认失败

这些是模型的默认倾向，不是偶发错误。写提示词时就要反向约束，出图后逐条查：

| 默认失败 | 表现 | 反向约束 |
|---|---|---|
| 主体居中悬浮 | 物体在画面正中，背景虚化到无信息 | 指定偏心位置与前后景关系，明确"桌面/墙面/地面"承托 |
| 塑料质感 | 表面过于均匀，无细微瑕疵，反光像塑料 | 指定材质与使用痕迹（划痕、水渍、纤维、氧化） |
| 虚假景深 | 全画面奶油状虚化，主体边缘发光 | 指定光圈感与清晰范围，要求"前景桌面清晰" |
| 完美对称 | 左右镜像、构图工整到不真实 | 指定主体偏左/偏右、桌沿切入、画面留一处不对称 |
| 廉价 3D | 高光锐利、阴影脏、边缘硬 | 明确"摄影"而非"渲染"，要求自然投影与次表面散射 |
| 图库式叙事 | 人手递文件、团队围桌、握手 | 换成物、局部、状态、痕迹；不出现完整人物 |

## 7. 看图淘汰清单

生成后必须实际打开图片，逐项过；任一明显失败即重生成，不得靠图注掩盖：

- 有明确的视觉概念，还是通用图库式表达？
- 构图是否有取舍与视觉重心（不是默认居中）？
- 材质、光影、透视是否正确？放大后细节是否成立？
- 是否服务于文章观点与该图职责？是否与全篇光线、色温一致？
- 在 390px 小屏上是否还读得出来？按 `cover_focal` 裁到 2.35:1 与 1:1 后主体是否还在？
- 有无错误文字、水印、多余手指、畸变结构、无意义装饰？

逐图记录：`职责｜可见主体｜来源/授权｜景别与视角｜邻接解释｜裁切/安全区｜信息增量｜保留或删除`。**没实际看图时，主体与景别写 `UNVERIFIED`**。

## 8. 来源定性

同一张图只能有一个主职责：实拍 `photo` / 资料 `archival` / AI 示意 `ai` / 证据 `evidence` / 数据 `data`。

- `资料/实拍` 必须在图注或紧邻来源行写明出处与授权（馆藏号、CC BY/CC0、摄影者、档案号），否则 Gate 2 拦截。
- **AI 生成图不能承担 `资料/实拍/证据/数据`**；渲染器对 AI + 资料/实拍、AI + 证据/数据硬拦截。
- `证据/数据` 必须有可核 HTTP(S) 链接，且不能是生成图。
- 文件名与 alt 只是声明，不能证明图中主体。
- 图注写"看到了什么"，不写"怎么做的"。**alt 就是版面图注**：`证据/数据/资料/实拍` 整句照印，其余职责要满 6 个汉字才印，写不满就留空——留空好过印一句"配图一"。不出现"AI 生成示意""素材说明""待补素材"这类制作标签；来源与授权留在侧车。

## 9. 规格与交付

- 封面目标 2.35:1（建议 1080×460 或 900×383）；正文横图长边 1200px，竖图短边 800px；单图压到约 1MB。
- 照片用 JPEG q94–96（4:4:4），图形、纯色与透明才用 PNG。交付前读回存盘文件核对，不以内存对象自证。
- 命名用语义路径 `images/fig-desk-three-roles.jpg`；职责与说明写进 Markdown 的 alt 与侧车。
- 低像素只在 Gate 2 提示，不硬阻断；预览嵌图仅为查看，不替代正文上传。
