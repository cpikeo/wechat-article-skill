# 图片艺术指导（按需读取）

设计判断与资产职能的唯一权威入口是 SKILL.md；本文件是它的工艺展开，不另设固定模板或禁用风格。核心命题：**让图片从"文字的配图"升级为"文章观点的视觉表达"**。高级 ≠ 漂亮；一张合格配图必须同时具备艺术表达、内容价值、出版级构图。

渲染器只负责素材接入、路径、安全、比例与输出验证，**不冒充能自动判断审美**。艺术指导由编辑/模型在生成前完成，质量淘汰由实际看图完成。

## 0. 强制工作流

**洞察 → 策划单 → 生成 → 实际看图淘汰 → 接入 Markdown → 预览裁切核对。**

- 生成任何图片前，必须先写下面第 1 节的七项策划单；没有策划单不生成。
- 生成后必须实际打开图片逐项过第 6 节淘汰清单；明显失败就重生成，**不得用图注掩盖低质量**。
- 不把每个段落画成一张直白说明图。优先用隐喻、局部、材质、人物状态、空间关系表达观点。
- 纯文字足够时不配图；没有信息增量就删，不为填空反复生成。

## 1. WORLD-CLASS Image Brief（生成前必填）

每张图一条，七项缺一不可，用具体名词与物理条件，不用形容词堆砌：

1. **内容洞察**：这张图要表达哪个观点或情绪？对应正文哪一句/哪一节？
2. **视觉概念**：真实场景 / 艺术隐喻 / 静物 / 纪实 / 博物馆 / 科学可视化，六选一或组合，并说明为什么。
3. **主体与动作**：画面里有什么、处于什么状态、正在发生什么；不要"一个物体悬浮在模糊背景前"。
4. **镜头与构图**：景别（远/中/近/特/微距）、机位（平/俯/仰/侧/局部切入）、主体位置（偏心/三分/框架）、前中背景纵深、负空间比例、视觉重心。
5. **光影与材质**：光源方向与性质（自然侧光/柔和漫射/逆光/局部聚光）、材质物理质感、真实投影与反射、微观细节。
6. **色彩与艺术方向**：主色/辅助色/背景色/局部强调色，低饱和自然克制；参考的摄影语言与情绪。
7. **输出约束**：画幅比例、主体安全区、`cover_focal`、禁止文字/水印/畸形结构/廉价 3D/过度磨皮/虚假景深。

禁止用 `masterpiece / 8K / ultra realistic / cinematic` 代替以上任何一项。

## 2. 六类视觉表达（按内容选，不是六套模板）

| 表达 | 适用内容 | 关键控制 | 避免 |
|---|---|---|---|
| Editorial Photography 杂志编辑摄影 | 观点、文化、生活方式 | 大胆构图、真实存在感、克制 | 商业图库摆拍 |
| Conceptual Photography 概念隐喻 | 抽象论点、评论、分析 | 一个可记忆视觉符号承载观点 | 把文字直译成画面 |
| Fine Art Still Life 艺术静物 | 器物、工艺、慢叙事 | 材质、光影、比例、留白 | 塑料感、悬浮居中 |
| Documentary Photography 人物纪实 | 人物、现场、报道 | 自然动作、真实情绪、环境关系 | 摆拍微笑、磨皮 |
| Museum Aesthetic 博物馆典藏 | 标本、器物、科学、知识 | 标本式呈现、中性背景、精确 | 装饰性堆砌 |
| Scientific Visualization 科学可视化 | 机制、结构、流程、数据 | 信息准确、层级清晰、零虚构数据 | 用生成图冒充实测 |

同一篇文章可混用，但整篇保持统一的摄影语言；不同类型服务不同职责，不全文套一种 AI 插画。

## 3. 构图与镜头语言

- **景别序列**：远景定场 → 中景关系 → 近景动作 → 特写/微距材质。一篇之内至少两种景别，避免全篇同景别。
- **视角**：默认避免平视居中；优先非对称、偏心、框架、局部切入，制造空间张力。
- **空间**：明确前景/中景/背景纵深；用遮挡、透视、光影分层，而非背景一律虚化。
- **比例与重心**：主体大小与留白比例服从观点；负空间是构图的一部分，不是浪费。
- **裁切**：封面用 `cover_focal: x% y%` 指定焦点（默认 50% 50%），预览据此模拟 2.35:1 与 1:1 双裁切；非对称构图必须显式给焦点，否则安全区裁切会切掉主体。

## 4. 材质与光影

按材质写物理质感：纸张纤维与毛边、金属氧化与拉丝、玻璃折射与厚度、陶瓷釉面与胎体、木材纹理与端面、织物褶皱与织纹、石材颗粒、皮肤毛孔与次表面散射、植物叶脉与通透。
光线写方向与性质：自然侧光塑造体积、柔和漫射保留细节、逆光勾边与通透、局部聚光制造焦点；投影必须与光源一致。
拒绝：塑料质感、过度锐化、虚假景深、廉价 3D 渲染、过度磨皮、不合理反射、无影悬浮。

## 5. 色彩与整篇叙事

每篇文章独立确定摄影色彩方向（主色/辅助色/背景色/局部强调色），低饱和、自然、克制；**不机械地把图片染成主题强调色**。六主题只影响版式与图片衬边/色调倾向，不生成固定图片模板。

整篇图片叙事按职责差异化，保持色调/材质/光线/摄影语言一致，但景别与构图必须变化：

| 位置 | 视觉任务 | 构图重点 |
|---|---|---|
| 封面 | 建立视觉记忆 | 单一主视觉、强概念、显式焦点 |
| 正文首图 | 建立情境 | 具体场景与主体、定场景别 |
| 章节图 | 辅助观点 | 与上一张不同的表达与景别 |
| 解释图 | 解释机制 | 结构清晰、信息准确、零虚构 |
| 证据图 | 可核对记录 | 真实来源，不用生成图 |
| 细节图 | 材质与可信度 | 特写/微距、真实纹理 |
| 结尾图 | 情绪与思想收束 | 安静、留白、有余韵 |

渲染器对"全文 ≥3 张图同一表达方式"发出同质化预警；连续三张独立图无正文间隔也预警。

## 6. 生成后淘汰清单（实际看图逐项过）

任一明显失败即淘汰重生成，不得加图注掩盖：

- 是否有明确视觉概念，而非普通图库式表达？
- 是否有独特构图与明确视觉重心（非默认居中悬浮）？
- 材质/光影/透视是否有错误？细节是否真实自然？
- 是否符合文章观点与图片职责？是否与整篇视觉方向一致？
- 是否适合小屏阅读与 `cover_focal` 裁切？
- 是否出现错误文字、水印、畸形结构、无意义装饰？

逐图记录：`职责｜可见主体｜来源/授权｜景别与视角｜邻接解释｜裁切/安全区｜信息增量｜保留或删除`。

## 7. 来源定性（不可混淆）

同一张图只能是：实拍 photo / 资料 archival / AI 示意 ai / 证据 evidence / 数据 data 之一为主职责。
- `资料/实拍` 图注或紧邻来源行必须写明出处与授权（馆藏号、CC BY/CC0、摄影者、档案号），否则 Gate 2 拦截。
- **AI 生成图不能承担 `资料/实拍/证据/数据` 职责**；渲染器对 AI+资料/实拍、AI+证据/数据均硬拦截。
- `证据/数据` 必须有可核对 HTTP(S) 链接，且不能是生成图。
- 封面必须写 `cover_note`（来源、授权、是否 AI）；非对称构图写 `cover_focal`。
- 文件名与 alt 只是声明，不能证明图中主体；未实际看图时主体/景别/安全区写 `UNVERIFIED`。

## 8. 预览与分辨率

打开 `*_预览.html`，切换 320/360/375/390/430 与 iOS/Android 字体栈，看图片比例、章节间距；点「封面裁切」用 `cover_focal` 核对 2.35:1 与 1:1 双取景，主体是否被切掉只看这一个面板。复制正文不含预览 chrome。与真实草稿并排截图对照，无真机截图一律 `UNVERIFIED`。

封面目标 2.35:1，建议 1080×460、900×383 基线；正文横图宽 1200px、竖图短边 800px。低像素 Gate 2 提示不硬阻断；大图压到约 1MB。可选本机工具（运行时不依赖）：`sips -Z 1400 图.jpg` 或 `magick 图.jpg -resize 1400x -quality 82 图.jpg`。

命名用语义路径 `images/fig-busbar.jpg`；引用职责与说明写入 Markdown。最终素材完整交付，预览嵌图只为查看，不替代正文上传。
