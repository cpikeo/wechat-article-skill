## 从 brief 到资产

把用途、主语、构图、镜头、光照、材质、色盘、画幅与移动裁切写进描述；同篇保留关键物理条件的一致性，不要求逐字复制 Prompt。不要靠「masterpiece／4K」代替方向。纪实图不为色盘统一而改事实。

例如解释配电设施：铜排与螺栓近景，平视，柔和顶光，冷灰柜体、低饱和铜色，3:2；若生成，说明「AI 生成示意」，不称为项目实拍或证明技术细节。

生成或下载后过目主语、错误构造、多余文字、水印、授权与来源。没有信息增量就删，不为填空反复生成。命名用 `images/fig-busbar.jpg` 这类语义路径；引用职责与说明写入 Markdown。

## 封面与分辨率

首图目标 2.35:1，建议1080×460，900×383作为输入基线。预览提供中央1:1模拟裁切；不同入口与客户端裁切不能只靠本地模拟认证。没有可靠出处的已有封面只能作为练习素材，不当真实记录。

正文建议横图宽1200px、竖图短边800px；最终判断取决于显示宽度与细节。低像素由 Gate 2 提示，不作发布硬阻断，但不把所有小示意图称为「必糊」。大图片压到约1MB内，保持清晰；压缩不是放大低清图的替代品。

可选本机工具（运行时不依赖这些工具）：

```bash
# macOS
sips -Z 1400 images/图.jpg
# 已装 ImageMagick 时
magick images/图.jpg -resize 1400x -quality 82 images/图.jpg
```

看预览中的图片本身与正文上下文，避免只看资产表。确认图注、字迹、小屏缩放、两种封面裁切；修改回源 Markdown。最终素材完整交付，预览嵌图只为便于查看，不替代正文上传。
