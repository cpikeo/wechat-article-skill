# 公众号 HTML 的工程边界

SKILL.md 决定设计；check.py 是本 Skill 保守的输入约束，不是微信全部支持能力的证明。

正文使用内联样式、section/p/span leaf、语义table/th/td、系统字体、图片 max-width:100%；拒绝脚本、事件属性、外部CSS资源、class/id、定位、grid、非本地图片。代码文字中出现CSS关键字不应误判为真实样式；仅纯pre拒绝，代码pre-wrap保留空格并允许折行。

有限flex、语义表格、圆角、细线与代码pre-wrap等是现有执行方式；微信编辑器与客户端清洗可能改变它们。浏览器通过、复制成功、上传成功都不证明真机排版一致。

预览不是发布正文：工具栏、资产表、封面裁切、模拟标题作者与首屏线不复制。预览嵌图片便于独立查看；复制仍指向本地素材，手动编辑器须上传替换。API 上传后才替换为微信图片 URL。正文来源链接以可见地址输出，是否可点击取决于平台权限。

真实验收要在目标公众号检查：粘贴／API 草稿后正文顺序与字段，保存再打开的样式与图片，手机预览的长表／代码／裁切。没有登录环境时如实列为未验证，不写「PASS 必定兼容」。
